# 🌙 Crimson Dusk — VS Code Theme

A carefully crafted **maroon-based dark theme** designed for **comfort, focus, and elegance** during long coding sessions.

---

## ✨ Why Crimson Dusk?

* 🎯 **Eye-friendly colors** — reduces strain during long hours
* 🌸 **Soft maroon aesthetic** — calm, minimal, and modern
* ⚡ **Balanced contrast** — clear readability without harsh brightness
* 🎨 **Consistent UI design** — editor, sidebar, terminal all aligned

## 🚀 Installation

1. Open **VS Code**
2. Go to **Extensions**
3. Search for **Crimson Dusk**
4. Click **Install**
5. Select theme:

   ```
   Preferences → Color Theme → Crimson Dusk
   ```
